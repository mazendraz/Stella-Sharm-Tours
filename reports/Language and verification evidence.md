The LCP element was the homepage hero image and the first gallery image on the trip page. The homepage image already had high fetch priority and was discoverable in the initial document. Measure transfer time for the exact first poster and gallery variant on staging, reduce the bytes for the mobile crop, and check competing early downloads. ## Seven core languages

Each public dictionary has **140 keys**, each admin dictionary **1,254 keys**. The key and message-argument checks passed. The bundled content contains **444 English source strings** and **409 six-language translation rows**. The remaining source entries are language-independent strings such as times. The source hash and numeric-fact tests passed. The catalog’s trip titles, duration and operating-day strings, highlights, inclusions, exclusions, optional items, itinerary descriptions and generated highlight summaries were checked against the source inventory. The missing return-time field below shows why dictionary coverage alone cannot verify a release.
