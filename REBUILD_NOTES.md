Other checks the spec asked for:

- `runDays`: **0 = Sunday** (public site uses `Date.UTC(1970,0,4+day)`); the site prefers `run_days` and only falls back to `days_label`.
- `privateOnRequest` vs `format`: data shows `both + privateOnRequest` (30 trips) and `private` (8). The editor now has **Format** (Group / Private / Group + private) and, for Group + private, **Private price** = _On request_ or _Supplement %_; the two stored fields are derived on save, so they can’t contradict.
- Package price on the site: the package’s own price rows if any, otherwise the **sum of its trips’ main prices** (“from €340”). Admin shows the same rule (“Shown on the website as …”).
- SEO fallback: confirmed — empty SEO title/description fall back to title/summary.
- Previews: signed preview links exist for trips/packages (`/t/`) and collections (`/c/`) only. There is **no homepage preview mechanism**, so the homepage editor offers “View live site” instead.

## 2. Backend changes (all additive)

- `admin-archive.ts` (new): archive/unarchive for trips & packages, collections (only `normal`, only when empty), hero slides, FAQ items; collection **unpublish** (was missing). Each records a revision, so Undo and History work.
- Migration `0004`: `faqs.archived_at` (nullable). FAQ restore keeps `archivedAt`.
- Lists accept `?archived=1` (trips, packages, collections, FAQ) and exclude archived items by default.
- Requests: `GET /requests/counts`; list search also matches email and **trip titles in any language**; filters `from/to` (received, Cairo dates), `tripFrom/tripTo`, `assigned`; list returns `tripItems [{title, dayIndex}]`; detail items ordered by day.
- **Bug fix**: correlated subqueries used `${table.id}`, which Drizzle renders unqualified (`"id"`), so Postgres bound it to the inner table. That is why `tripTitles` was always `[]` and why package-part prices were wrong. All such subqueries now use table-qualified names.
- Trip/package lists add `coverMediaId`, `primaryAmountEur/primaryUnit`, `partsCount/partsSum/partsOnRequest`. Media list adds `used`. Where-used slides include a `name`.
- Duplicate: `slug` optional → `{slug}-copy`, `-copy-2`…; title gets “ (copy)” in every locale; status draft; placed right after the original.
- Audit: `entityId` filter; `entity=trip` includes the trip sub-entities; `entityTitle` for FAQ, requests (ref), users, settings and pages. `recordChange` skips no-op updates.
- Users: `409 SELF_CHANGE` for changing your own role or disabling yourself (last-owner check already existed).
- Sort stability: trips/packages/price list order by `sort`, then English title.
- 2FA setup is idempotent: a pending secret is returned again instead of being replaced.
- Bulk price preview accepts `round: 1 | 5` (default 1 = previous behaviour).
- Translation queue rows include `itemTitle`, `parentId`, `parentKind` for the “Where” column.
- `/me/sessions` returns `user_agent` and `current`; member sessions return `userAgent`.
- `basicsSchema` accepts `slug` (page address editable, with a warning).
- `admin-contracts.ts` declares all of the above (the contract layer rejects undeclared query/body keys); `tests/contracts/openapi.json` regenerated.

## 3. Deviations from the spec

- **Old admin kept working until parity**: not done incrementally. The whole admin was rebuilt in one pass on `admin-rebuild`; commits are split by area so it can be reviewed in order.
- **Request notes timeline (§9.7)**: not built (optional). The single internal note stays; the field shows “Last updated …”. History shows status/assignment changes from the audit log (owner/manager only — sales can’t read the audit log).
- **Package “Custom price”**: supported through the package’s own price rows (`PUT /trips/:id/prices`); “Use sum of trips” deletes them.
- **Homepage “How it works”**: exactly 3 steps (API rule), not “max 4”. Perks: exactly 4.
- **Hero “New slide”**: created directly (no fields are required to start), then opens the editor.
- **Translations “Reviewed” filter**: the queue API only returns items that still need work, so the state filter offers AI draft / Missing / Needs review / Waiting for approval.
- **Video trim**: the player shows the current processed clip; the timeline maps to the original upload (shown in a note).
- **Languages coverage %** for core languages: shown as “N to review” (from the queue) — the API has coverage numbers only for extra languages.
- **Editor drafts** (editor role on published items): shown as a banner; draft values are not merged into the form.
