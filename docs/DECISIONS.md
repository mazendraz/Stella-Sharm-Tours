# Decisions & defaults

Codex: **do not stop to ask about anything in this file.** Use the default, keep it configurable (env or admin setting), and add any new question to `QUESTIONS.md` at the repo root.

Owner update 2026-11-12: Codex authors all existing content for the seven core
languages directly. Store it in `data/i18n/` and seed it into the DB; no paid
translation service or self-hosted MT process is required for those languages.
Keep existing human translations and record AI authorship without claiming native review.

Standing owner rule (2026-11-12): every future content/UI change ships in all
seven core languages together, authored directly without a translation service.
Review corresponding translations whenever the meaning changes. Shared code,
layout and prices are changed once and verified in all seven locales. Missing
translations, stale copy and English fallback do not satisfy completion for a
new change. This rule applies automatically to future work.
