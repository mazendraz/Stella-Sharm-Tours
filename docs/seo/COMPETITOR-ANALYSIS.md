# Competitor and search-intent analysis

## Method and limits

Three web searches on 2026-11-27 (US-based search tool): "Sharm El Sheikh
excursions", "escursioni Sharm El Sheikh guida italiana", "Ras Mohammed White
Island boat trip from Sharm El Sheikh price". No rank tracker, keyword-volume,
backlink or traffic tool was available, so this file reports **who appeared
and what their pages offer**, not positions, volumes or authority scores.
Results from Italy or the UK may differ from a US-located search. Repeat with
a rank tracker set to Italy/UK before setting targets.

## What competitors' pages do well

- **Price per adult up front** and what the price covers. Reseller listings for
  this trip type ranged roughly $17–$55 per adult in the search snippets
  (undated, reseller prices — indicative only).
- **Inclusions/exclusions spelled out**: transfers, lunch, snorkel gear,
  national-park fee (often "not included, pay on the spot"), drinks.
- **Practical caveats** that answer real questions: White Island is
  tide-dependent; advance booking advised in peak months.
- **Language of the guide** is a headline attribute in Italian results.
- **Destination guides** ("things to do", resort guides) capture
  informational queries and link to bookable trips.

## Where Stella can be more useful (without copying anyone)

1. **First-party specifics**: exact pickup times per area, real return times
   (already shown for some trips), what the boat lunch actually is (already
   listed for Ras Mohammed — few listings are that specific).
2. **Transparent EUR prices from the database**, including child and per-car
   prices, plus a clear "what is not included" list (only 6/38 trips have one).
3. **Private versions of every trip** — a headline feature competitors bury.
4. **No prepayment** — booking by request and WhatsApp confirmation; state it
   plainly with the confirmation steps.
5. **Answer the tide/park-fee/children questions** per trip once verified.
6. **Italian**: if Italian-speaking guides are available, say so per trip;
   if not, do not imply it.
