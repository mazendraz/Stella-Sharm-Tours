## How to run it

- Run monthly, same day of month, logged out or in a fresh profile, no custom
  instructions, location set to the target market (Italy or UK) where the
  platform allows it.
- Use the exact prompt text. One new chat per prompt.
- Record in the table below (copy it per run into `ai-visibility/YYYY-MM.md`).
- **Mention** = the name appears. **Citation** = a link to
  stellasharmtours.com is given as a source. **Recommendation** = named as a
  suggested provider; position = order in that list. **Referral** = a visit,
  seen in Umami by referrer (separate from the chat result).
- AI answers vary between runs; compare trends over months, not single runs.

Result columns per run: platform · date · mentioned (y/n) · cited (y/n) ·
position · competitors named · sources cited.
